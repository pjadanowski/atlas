Every page should answer one question.

Developers should never need to search twice.

Every click should reveal more detail.

The interface should become invisible after five minutes.

The documentation should feel like reading a well-designed book.

Every animation should explain, never decorate.

Whitespace is content.

Information density should be high without feeling crowded.

Every component should have one purpose.

If removing a visual element makes the page clearer, remove it.

Good design is measured by understanding, not beauty.
